# Account & Password Administration

## Overview
Configured domain password and account lockout policies, performed account administration tasks, and investigated account-lockout activity using Splunk.

## Project Evidence

### 1. Password & Account Lockout Policy
- Screenshot: `#1 Password & Account lockout policy.png`
- Configured password policy settings.
- Set the account lockout threshold to **3 invalid logon attempts**.
- Configured lockout duration and counter reset to **30 minutes**.

### 2. Account Unlock
- Screenshot: `#2 Account Unlock.png`
- Demonstrated the account unlock process using Active Directory Users and Computers.

### 3. Detect Account Lockout Using Splunk
- Screenshot: `#3 Detecting Account Lockout using Splunk.png`
- Used Splunk to investigate Windows Security events.
- Reviewed failed logon and account-lockout activity.

### 4. Password Reset
- Screenshot: `#4 Password Reset.png`
- Demonstrated resetting a domain user's password through Active Directory Users and Computers.

## Result
- Configured domain password and account lockout policies.
- Practiced password resets and account unlocking.
- Used Splunk to investigate authentication-related security events.
